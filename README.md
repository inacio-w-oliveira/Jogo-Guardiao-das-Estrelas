# Guardião das Estrelas

## Desenvolvedores

## História do jogo
Em um futuro distante, uma chuva de meteoros ameaça as estações espaciais da galáxia.
Você pilota a última nave guardiã e precisa desviar de todos os meteoros que caem.
Quanto mais você resiste, mais rápidos eles ficam. Quem conseguirá a maior pontuação?

## Como jogar
- Setas esquerda e direita: mover a nave
- Espaço: pausar e continuar
- ESC: fechar o jogo

## Tecnologias utilizadas
- Python
- Pygame (imagens, sons, eventos e telas)
- pyttsx3 (voz do jogo)
- cx_Freeze (executável com `python setup.py build`)
- Git e GitHub (controle de versão)
